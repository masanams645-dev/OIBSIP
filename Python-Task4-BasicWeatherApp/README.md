# Basic Weather App

## Objective
A Python application that fetches and displays real-time weather information for a user-specified city.

## Features
- Enter city name or ZIP code
- Display temperature in Celsius and Fahrenheit
- Display humidity
- Display weather condition
- Display wind speed
- Handle invalid city
- Handle invalid API key
- Handle network errors
- Validate empty input
- Check weather for another city

## Technologies Used
- Python
- Requests
- JSON
- OpenWeatherMap API

## How to Run
1. Install requests:
   pip install requests
2. Add the OpenWeatherMap API key in `main.py`.
3. Run:
   python main.py
4. Enter a city name or ZIP code.
